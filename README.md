# Prototipos de alta fidelidad — CanchaMatch

Prototipos de las 4 funcionalidades críticas del proyecto, diseñados en Stitch,
siguiendo la identidad visual "cancha nocturna bajo luces": azul noche (#122A45)
como base y verde lima eléctrico (#9AE85C) como acento.

## Pantallas

**01_login_bienvenida.png** — Autenticación (HU-01, HU-02, HU-04)
Pantalla de bienvenida con selección de rol (Jugador / Capitán / Organizador),
inicio de sesión con correo y contraseña, enlace de recuperación y acceso a registro.

**02_reserva_cancha.png** — Búsqueda y reserva de cancha (HU-06, HU-07, HU-08)
Buscador de sede/tipo de cancha, selector de fecha, grid de horarios con estados
libre/ocupado, resumen de horas seleccionadas y costo total, y método de pago.

**03_tabla_posiciones.png** — Tabla de posiciones en vivo (HU-16, HU-17)
Tabla de la liga amateur con badge "EN VIVO", posiciones (PJ, PG, PE) y el
próximo partido del equipo del usuario.

**04_perfil_fidelizacion.png** — Perfil y fidelización (HU-18, HU-19)
Perfil del jugador con nivel de liga, puntos acumulados, progreso hacia el
siguiente nivel y beneficios canjeables.
